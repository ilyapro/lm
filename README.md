# lm

Minimal project scaffold for future application work.

## Current State

This repository intentionally avoids committing to an application framework or runtime stack. It provides a small directory layout, shared formatting defaults, and npm scripts that can be extended once the project goal is concrete.

## Layout

- `src/` - application source code once a stack is selected.
- `tests/` - automated tests.
- `docs/` - project-facing documentation.
- `scripts/` - local automation used by package scripts and development workflows.

## Commands

```sh
npm run check
npm test
```
